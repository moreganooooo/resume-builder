# Resume Scoring Framework

## Categories

1. Accuracy (0-25)
2. Human Believability (0-25)
3. Specificity (0-20)
4. ATS Compatibility (0-15)
5. Formatting Consistency (0-15)

Total: 100

## Manager Test

For every bullet ask:

"What would a hiring manager ask next?"

If the candidate likely cannot answer, flag the bullet.
