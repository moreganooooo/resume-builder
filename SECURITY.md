# Security Policy

## Supported Versions

We release patches and security fixes for the active main branch:

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |

## Reporting a Vulnerability

We take the security of Resume Builder and sovereign personal data very seriously.

If you discover a security vulnerability, please do **NOT** open a public issue. Instead, please report it privately:

1. Draft an email detailing the vulnerability, reproduction steps, and potential impact.
2. Send it to the repository maintainer or open a private GitHub Security Advisory.
3. We will respond within 48 hours to acknowledge receipt and coordinate a fix.

Thank you for helping keep Resume Builder and its users secure!
