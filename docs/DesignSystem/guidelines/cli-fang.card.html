The TUI is the product's face and the CLI is its front door, so they use one palette: Mauve for the program name, Blue for section headings, Peach for flags, Subtext for description. Fang supplies this over Cobra, which means --help, version output and error formatting stop being three separately hand-styled things. Errors follow the same rule as everywhere else — plain language first, the fix named, no stack trace above the fold. --no-color and NO_COLOR both strip styling and leave the structure intact.
