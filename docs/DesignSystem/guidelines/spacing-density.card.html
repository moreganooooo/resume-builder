Density is chosen from terminal height, not preference, and switches at 30 rows — the point below which the chrome stack plus a comfortable list stops fitting. Horizontal padding never changes: columns are the one thing that must stay aligned across both modes. Nothing is removed in compact — the score, the tag and the company are all still there. A mode that hides information is a different screen, not a density.
