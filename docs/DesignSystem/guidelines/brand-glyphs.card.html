Nerd Font PUA glyphs are the product default; these are the browser-safe fallback. Emoji are banned.
Four keys share ✦ U+2726 — hint, gem, magic, sparkOpen. Screen titles are already bracketed ✦ … ✧, so any of the four as a header icon renders a doubled sparkle. Pick a glyph that is not the bracket: ✎ edit for rewriting, ⚙ utility for settings, ▥ report for documents.
An unknown key is not silently printed as text — Glyph warns and renders ◌ in Overlay, so a typo looks wrong rather than deliberate.
