THE ESCAPE STACK — esc POPS EXACTLY ONE LEVEL
Modal / form→ paneHuh owns the keys. Esc cancels without committing.
Detail pane→ list paneTab also moves between the two panes.
List pane→ screenFocused pane takes the Blue border; the other is Overlay.
Screen→ main menuInstant, never sprung.
Main menu→ confirm quitThe only level where esc asks rather than acts.
WHO OWNS THE KEYBOARD
One owner at a time. While a modal, a form or the command palette is open it consumes every key except its own exit. Global shortcuts do not fire through it — a q typed into a search field is the letter q.
Focus is always visible. If a surface accepts keys, something on screen is Mauve or Blue. There is no state where the user must guess where a keystroke will land.
Esc never destroys work. It cancels a form that has not committed and closes a view. Anything that discards typed text confirms first — and offers u to undo afterwards.
Ctrl-c is not esc. It quits the program from anywhere, at any depth, without confirming. That is the terminal's contract and the product does not override it.
