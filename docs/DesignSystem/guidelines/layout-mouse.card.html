Keyboard stays primary — the product's stated posture. Mouse support exists because clicking a tab is what people try first, and a tab that does nothing when clicked reads as broken. Every zone below maps to a binding already in the footer.
ZONES WORTH MARKING
✓ filter tabs → same as ←/→
✓ sidebar rows and board cards → moves the cursor, does not open
✓ menu entries → single click selects, double opens
✓ footer keybinding hints → fires that action
✓ modal confirm / cancel → Enter / Esc
ZONES TO LEAVE ALONE
✕ drag to move a card → columns are unordered sets; there is no insertion index to drop onto
✕ text selection inside panes → mouse capture breaks the terminal's own copy
✕ scroll-wheel as the only way to page → it may pass through; space must still work
✕ hover-only meaning → there is no hover state in this system
