ELAPSEDTIMER
Toast or panel? A toast reports something that already happened and needs no answer. Anything the user must act on is a panel or an inline error — a toast that expires takes the user's only chance to act with it. Success and info auto-dismiss; warnings and errors wait for a keypress. Maximum three, with older ones collapsed rather than scrolling, so the newest is always in the same place.
