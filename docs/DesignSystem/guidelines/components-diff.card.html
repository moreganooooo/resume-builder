A TAILORED BULLET
THE RULES
The sign column is never dropped. Colour is not the only signal, and a diff pasted into a plain-text email still reads.
Removed text is not struck through. Strikethrough is unreliable across terminals, and where it renders the user can no longer read the original — which is the thing they need in order to judge the rewrite.
A rewrite is one decision. Paired −/+ lines sit adjacent with the Mauve ┃ rationale beneath, so accepting or rejecting has one obvious target.
Word emphasis is bold, not fill. A filled span at this size reads as redaction.
