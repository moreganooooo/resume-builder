The resume masthead: serif name, uppercase tagline, pipe-separated contacts.

```jsx
<PrintHeader name="Morgan Avery" tagline="SENIOR BRAND STRATEGIST | CONTENT LEAD"
  contacts={["(785) 555-0134", "morgan@example.com", "linkedin.com/in/morganavery", "Lawrence, KS"]} />
```

The tagline is uppercase in the data, not via CSS, and is budgeted by character count against its 15pt size.
