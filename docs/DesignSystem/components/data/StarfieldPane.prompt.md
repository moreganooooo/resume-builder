The empty detail pane. A twinkling starfield behind a centred Surface card — the product's one piece of pure delight.

```jsx
<StarfieldPane hints={[
  "To scan for new roles, press [ s ]",
  "To batch evaluate pending, press [ b ]",
  "",
  "Or use the CLI: resume build <jd_file>",
]} />
```

Hints must be the calling screen's own bindings — `s` scans on Jobs but cycles sort on Pipeline. Bracketed keys render Peach; the last line is muted.
