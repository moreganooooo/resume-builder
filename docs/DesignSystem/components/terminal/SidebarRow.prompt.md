The two-line row used by both the Pipeline and Jobs sidebars.

```jsx
<SidebarRow selected score={4.4} company="Callahan Creek"
  tag={<EmploymentTag type="full_time" />}
  subtitle="Creative Director  Fit 4.5 / Odds 3.9" />
```

Selection is a Mauve `┃` plus bold, never a row background. Unselected rows dim as a whole so their internal colour coding survives.
